# 小番茄图片加密 / 解密

这个仓库提供 ComfyUI 节点和 Windows 桌面工具，两者使用同一套像素重排算法，可以互相加密、解密。处理过程在本机完成。算法使用固定规则，任何拿到图片和兼容工具的人都能解密。

## 安装和使用 ComfyUI 节点

1. 打开正在使用的 ComfyUI 安装目录，进入 `ComfyUI/custom_nodes`。如果在画布上已经能搜到「小番茄图片加密 / 解密」，可以直接跳到第 3 步。
2. 在 `custom_nodes` 目录打开终端，执行下面的命令。克隆私有仓库时，请使用有访问权限的 GitHub 账号。安装完成后，等当前队列结束，重启 ComfyUI 并刷新浏览器。

   ```powershell
   git clone https://github.com/xiekun3312/ComfyUI-CherryTomato.git
   ```

   也可以在 GitHub 选择 **Code → Download ZIP**，把解压后的仓库文件夹放进 `custom_nodes`。确认 `__init__.py` 位于 `custom_nodes/ComfyUI-CherryTomato/__init__.py` 或 `custom_nodes/ComfyUI-CherryTomato-main/__init__.py`。节点使用 ComfyUI 环境已有的 PyTorch 和 NumPy。

3. 双击画布，搜索 **小番茄图片加密 / 解密**，按 `加载图像 → 小番茄图片加密 / 解密 → 保存图像` 连接。节点有一个 `IMAGE` 输入和一个 `IMAGE` 输出。开关打开为 **加密**，关闭为 **解密**。
4. 点击运行。使用内置「保存图像」节点时，结果默认在当前 ComfyUI 的 `output` 文件夹。若启动时指定了输出目录或换用了其他保存节点，以对应配置为准。

## 使用 Windows EXE

1. 打开 [图像加密解密.exe](desktop/图像加密解密/图像加密解密.exe) 的文件页，点击 **Download raw file** 下载，然后在 64 位 Windows 上双击运行。桌面版可独立运行，无需启动 ComfyUI。
2. 点击 **选择图片…**，选取 PNG、JPG、JPEG 或 BMP。此时窗口只显示文件名。程序直接读取所选文件，无需建立输入临时目录。
3. 点击 **加密** 或 **解密**。程序会自动保存 PNG，并显示处理结果。调整窗口大小时，预览会等比例缩放。
4. 点击 **打开输出文件夹**，资源管理器会打开并选中刚生成的文件。**清除** 按钮位于「解密」右侧，只清空预览，当前选图和已保存的文件都会保留。

### EXE 的输出位置

桌面版固定写入以下目录。即使从其他位置启动 EXE，输出路径也相同。首次保存时会自动创建文件夹，因此电脑需要有可写的 `F:` 盘。

```text
F:\知识库\编程开发\图像加密解密\output
```

例如，选择 `示例.jpg` 并点击加密，会得到 `示例_加密.png`。再选择这个 PNG 并点击解密，会得到 `示例_加密_解密.png`。遇到重名时，新文件会自动加上 ` (2)`、` (3)` 等编号。

## 保存后再解密

需要之后还原时，请保存为 **PNG**，并在传输时保留原尺寸和像素。解密依赖像素排列，无需工作流或 EXIF 元数据。EXE 导出的 PNG 只保留重建像素所需的数据。使用 ComfyUI 时，是否写入工作流等附加信息由保存节点决定。
